# Timer

A simple countdown/timer UI demo for setting and running timers.

## Tech

- HTML, CSS, JavaScript

## Features ⏱

- Start, pause, reset, lap functionality

## Run

1. Open `timer.html` in your browser.
2. Enter duration and press Start.

## Files

- `timer.html` — UI
- `timer.css` — styles
- `timer.js` — behavior and countdown logic

---

**Notes:** Static demo; no installation required.
